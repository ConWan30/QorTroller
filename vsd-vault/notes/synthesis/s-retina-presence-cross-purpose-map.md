PREMISE. The input↔screen causal-presence primitive ([[s-retina-presence-product-thesis]],
[[s-cross-channel-latency-invariant]]) is purpose-agnostic: it certifies "a live human authored these pixels on
a certified device, now." Anti-cheat is the lead market; the SAME proof resells across five adjacent surfaces
the project already gestures at. Each row is design-only, with its honest scope.

1. STREAMING / SPECTATOR TRUST — "Verified Live" badge. A broadcaster's stream carries a recomputable presence
   attestation (the witness-stamp pattern the loop already uses) proving the footage is being authored live,
   not restreamed / pre-recorded / AI-generated. Defeats fake speedruns, restream piracy, and "is this VTuber
   actually playing" disputes. Buyer: streaming platforms, speedrun boards (a recomputable badge is exactly
   what leaderboards lack). Scope honesty: proves PRESENCE, not skill or identity.

2. REMOTE-TOURNAMENT ADMISSION. The cross-channel latency invariant is the admission gate for ONLINE
   tournaments where the rig cannot be physically inspected — the exact cloud-gaming-bot gap (WormVision /
   GeForce-NOW) named in the BT-calibration anchor. Server issues a nonce; client returns a coupling proof
   bound to it within a session window. Buyer: tournament organizers, esports platforms. This is the
   strongest non-anti-cheat-product framing because the deployer (the organizer) is a willing third party.

3. DATA-ECONOMY / MARKETPLACE PROVENANCE — "authored gameplay" label. Gameplay sessions/clips sold in the
   Curator marketplace carry a presence-provenance label proving human authorship on a certified device — the
   freshness/authenticity stamp training-data and highlight buyers actually want (provenance-clean, not
   AI-synthesized, not replayed). Plugs into the existing consent + CORPUS-SNAPSHOT + Curator machinery; the
   coupling proof is the data label, not a new chain primitive.

4. MANUFACTURER DEVICE-CERT — "retina-attestable" tier. A device-cert tier (Path A registry / tier system)
   that asserts a controller's telemetry is fidelity-sufficient to PRODUCE a coupling proof (1000 Hz, genuine
   trigger force curves). Certified controllers earn a higher trust tier because they CAN be retina-attested;
   generic pads cannot. Turns the presence primitive into a hardware differentiation lever for partners.

5. ACCESSIBILITY / COACHING — sensorimotor instrument (non-adversarial). The same machinery measures the
   PLAYER's own metrics: trigger→kill reaction lag, recoil-compensation residual ([[s-recoil-compensation-coupling]]),
   ADS-to-fire timing, and the session's measured glass-to-glass latency L (a by-product of the latency
   invariant). A coaching dashboard and a setup-latency diagnostic — the presence oracle re-pointed at the
   player as a benefit, not a gate. Strong goodwill / adoption surface; zero adversarial framing.

THE UNIFYING CLAIM. Five buyers, one primitive, no new FROZEN surface — because presence is a property of the
input↔screen causal bond, and that bond is the same whether you are policing a cheater, badging a streamer,
admitting a tournament entrant, labeling marketplace data, tiering a device, or coaching a player.

OPEN GATE (`possible`). All five are positioning, not built surfaces; each inherits the uncalibrated-invariant
risk from [[s-cross-channel-latency-invariant]] (no FAR yet) and adds its own integration scope (badge format,
nonce protocol, label schema, cert-tier predicate, dashboard UI). Sequence after the latency-invariant
calibration lands. No FROZEN-v1 / 228B PoAC / chain / IOTX touched; design-only.
