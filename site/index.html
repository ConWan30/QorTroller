What this is, and is not.

Is

A proof layer

It binds controller physics and match evidence into a receipt. Organizers and strangers can re-check published artifacts.

Is not

A kernel anti-cheat

It does not ban players, identify which human is playing, or catch a real person using an aimbot. Advisory until an organizer adopts it.
