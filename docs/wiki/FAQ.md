# FAQ

## Can anyone use this repo?

Yes. Clone it over HTTPS. Run the public verify commands. Open Discussions. Fork and send a PR.

## Why doesn't a fresh clone "just work" as a live anti-cheat?

Live capture needs hardware, an operator rig, and local env files. Those secrets are intentionally not in git. The public path is verify-the-protocol, not impersonate-the-operator.

## Is Qoresence the same project?

No. Qoresence is the observation plane. QorTroller is the parent truth plane. They share a founder and a family, not a claim surface.

## Where do I report a security issue?

https://github.com/ConWan30/QorTroller/security/advisories/new — not a public issue.
