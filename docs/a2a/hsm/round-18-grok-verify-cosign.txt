### Hammer answers (1–7)

**1. Threat model — CLOSED for external operator_id**  
`fully_authorized = guardian_ok ∧ operator_sig_ok ∧ operator_id_authenticated`.  
Bridge can always force `guardian_ok` (AWS creds).  
`operator_id_authenticated` requires recover(raw_digest, op_sig) == `operator_id` with `_is_address`.  
Probed:
- wrong-key sig → `sig_ok=True`, auth=False, full=False  
- junk 65B → both False  
- EIP-191 wrap → recoverable wrong addr, full=False  
- cross-package transplant → guardian ok, auth=False  
- mutate `operator_id` / `decision` after dual → guardian fails (preimage-bound), full=False  

**Only collapse:** `operator_id` = bridge-controlled address (F1).

**2. Recover soundness — CLOSED**  
`sign_msg_hash` / `recover_public_key_from_msg_hash` = raw 32B digest (not EIP-191). Malleability does not change recovered address under correct `(r,s,v)`; wrong form fails auth.

**3. Digest re-derivation — CLOSED**  
Both paths call the **same** `build_graduation_attestation_preimage(...)` then SHA-256. Cosign digest matches attestation `digest_hex`. Tampering stored `digest_hex` is ignored (re-derive wins). Guardian `pub.verify(..., preimage, ECDSA(SHA256()))` ≡ digest-mode over the same bytes.

**4. RAW vs EIP-191 — CLOSED**  
Method flag only admits verification attempt. Recover always over raw re-derived digest. Flag=`raw` + EIP-191 body → wrong recover → not authorized. Sufficient for v1; optional later: refuse non-65B / enforce low-s explicitly.

**5. Bridge-wallet refuse — OPEN (F1)**  
Lowercase checksum compare is fine (one secp256k1 → one address). No alternate derivation bypass. **Must refuse inside `add_operator_cosignature` + fail-closed in `verify_*` / `cryptographic_dual_key_satisfied`**, not only CLI — future non-CLI callers will skip the guard.

**6. Scope/rails — HELD**  
`operator_dual_key_present` untouched (O3 supersede still declarative — correct). Helper is intentional dead-until-wired primitive (PCRA-shaped). CLI env-only key; 0-IOTX; no auto-apply; CANDIDATE. Good.

**7. Honest claim — COMPLETE**  
Notes correctly scope to address-keyholder auth; key theft / blind-sign residuals named; not cognitive intent; not a capability token.
