## 2. Re-issue / re-anchor

**Backend select under `MFG_CA_BACKEND=kms`:** routes to `KMSIdentityBackend`; **does not** auto-generate / touch the software key file. `key_path` is irrelevant on the kms branch. Good.

**Re-issue:** yes —  
`MFG_CA_BACKEND=kms` + `provision_device_mfg.py --dry-run`  
= local re-sign + persist. Correct.

**Re-anchor:** **no — not with `--execute` on the live device.**

VMDR:

```solidity
require(!registered[deviceId], "VMDR: already registered");
// revoke: active=false only; registered stays true forever
// docs: replace = revoke + NEW deviceId
```

So for `581a836c…`:

- `--execute` → **revert** (`already registered`), not orphan overwrite  
- `revoke` then re-register same `deviceId` → still **revert**  
- new `deviceId` → breaks device identity canon (wrong)

**Honest paths (pick one; don’t pretend `--execute` re-anchors):**

| Path | Meaning |
|------|--------|
| **A (recommended)** | Small VMDR writer: `updateBirthCertHash(deviceId, newHash)` `onlyOwner` (+ optional `UpdateBirthCert` event). Then operator-fired re-anchor. **CA migration needs this for inventory N≥1.** |
| **B** | No on-chain re-anchor for existing device. Keep software-signed hash on-chain; KMS only for **net-new** devices. Flip is partial; `verify_device_cert` VALID only against the **old** cert JSON forever for `581a836c`. Do **not** demote F-DECON-3.2 as “closed” until inventory policy is explicit. |
| **C** | New VMDR + Lens rewire — too big for this pass. |

Migration doc step 4 (“re-`registerDevice`”) is **false against current Solidity**. Fix the runbook before ceremony day.

## Top 2 footguns (pin hard)

1. **VMDR one-shot:** `registerDevice` never updates `birthCertHash` for an existing `deviceId`; revoke does not free the id. **`--execute` re-anchor will burn gas and fail.** Ceremony without Path A/B choice above is unsafe.

2. **“Re-issue then flip then verify VALID” under current chain:** KMS cert hash ≠ on-chain software hash → `verify_device_cert` **INVALID (birthCertHash mismatch)** even if sig is perfect. Operators will think KMS is broken; it isn’t — **anchor can’t move**.
