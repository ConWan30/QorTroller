### CRITICAL — Inc-2 URI prefix dead on real drafts

`draft_audit_entry` sanitizes `audit_id` via `_safe_id_segment` (`:` `#` `/` → `_`):

| audit_id | real `draft_uri` |
|---|---|
| `pcra:anchor#wallet_iotx` | `draft://audit_entries/pcra_anchor_wallet_iotx` |
| `pcra:docs/a2a/x.md#poep_enabled` | `draft://audit_entries/pcra_docs_a2a_x.md_poep_enabled` |

Inc-2 filters on `_PCRA_URI_PREFIX = "draft://audit_entries/pcra:"` → **startswith fails** → **0 SEL labels** in prod.

Tests pass because `_FakeGuardianGenerator` builds `draft://audit_entries/{audit_id}` **without** sanitization.

**Minimal fix:**
```python
_PCRA_URI_PREFIX = "draft://audit_entries/pcra_"  # post-_safe_id_segment of "pcra:"
```
Fake generator must call real `_safe_id_segment` / `GUARDIAN_AUDIT_DRAFT_PREFIX`. Add test that real sanitization path still produces labels.
