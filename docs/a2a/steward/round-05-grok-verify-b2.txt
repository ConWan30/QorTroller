### F3 — MED: preimage binding is mostly theater
Domain tag `VAPI-MPJA-JOIN-v0` + `session_id` + **sorted boolean bits** + scorecard/wmp roots.

| Bound? | Surface |
|--------|---------|
| yes | session_id, scorecard_root, wmp_root, bitmap bits |
| no | kas verdict/commitment, posp verdict/root, ledger tx, w3s evidence |

Boolean bits encode “flags that are true,” not *what* was joined. Two COMPLETE joins with different KAS truth collide.  
Proposing a preimage **draft-only** is not spend-creep (no executor call, no chain import) — but calling it what “Sentry WOULD anchor” without binding surface hashes is overselling.

**Fix (this commit):** note: “completeness-certificate hash, **not** content-bound join root.”  
**Defer v0.1:** bind kas_commitment / posp roots / anchor_tx when present.

### F4 — MED: BROKEN coverage is the right *class*, incomplete set
**Good (load-bearing, correctly tested):**
- ANCHORED + empty/whitespace tx → JOIN_BROKEN, no preimage
- pre-anchor COMPLETE with PENDING is valid (`ledger_anchored` optional) ✓
- malformed non-hex scorecard/wmp → BROKEN ✓

**Missed / wrong:**
| Case | Observed | Should |
|------|----------|--------|
| `ledger_anchor_tx="not-a-tx"` | JOIN_COMPLETE | BROKEN (tx shape) |
| scorecard `0x`+64hex | JOIN_BROKEN (malformed) | accept or normalize (real roots use 0x) |
| tx present, status PENDING | COMPLETE | at least note / soft-BROKEN orphan claim |
| any non-empty `kas_verdict` | present=True | presence OK for completeness; quality is separate |
| empty `session_id` | COMPLETE + hash | reject / BROKEN |

False-anchored is high-value and **already demoted in UI** (`ContributionPulse` ANCHORED-without-tx → PENDING). MPJA elevates that rail to steward draft domain — real, not novel physics.

**Other contradictions the “non-contradictory” claim implies but v0 skips:** session_id mismatch across surfaces; posp SYNCHRONIZED with no KAS; scorecard bound with no ledger entry; w3s_ok True with no ledger — all PARTIAL or invisible without real extraction.
