## 4. RECOMMENDATION STATE MACHINE

```
hard → RECOMMEND_SUSPEND | STAY_SUSPENDED   OK
soft → RECOMMEND_HOLD                      OK
clean+active → PRODUCT_OK                  OK
clean+inactive → RECOMMEND_RELIST          FOOTGUN
```

**RELIST:** DPIG cannot see operator legal-hold, abuse, fraud, or non-integrity suspend reasons. Clean integrity evidence ⇒ affirmative **RECOMMEND_RELIST** is unsafe advice that will feed the draft pipe in v0.1.

**Minimal safe v0:** clean+inactive → **STAY_SUSPENDED** + soft  
`"integrity clear; relist is operator decision (non-integrity suspend reasons invisible to DPIG)"`  
— or require explicit caller flag `integrity_class_suspend=True` before RELIST. Do not default-RELIST.

Hard-over-soft priority works (probed).
