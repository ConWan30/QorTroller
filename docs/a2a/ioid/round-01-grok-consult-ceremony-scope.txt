## Findings first

### F1 — Sequence is **right enough**; one optional fee step is under-specified

Canonical agent order (proven live):

| # | Step | Hard dependency |
|---|------|-----------------|
| 1 | Deploy DeviceNFT → `initialize` → `configureMinter` | — |
| 2 | `ProjectRegistry.register(name, **0**)` | type **0** = hardware (required if you ever `applyIoIDs`) |
| 3 | `ioIDStore.setDeviceContract(projectTokenId, NFT)` | needs **both** project owner + NFT address; **1:1, one-shot** |
| 4 | (opt) `applyIoIDs(projectTokenId, N)` **or** pay-as-you-go | fee path |
| 5 | `NFT.mint(to)` | minter + allowance |
| 6 | `ioIDRegistry.register(...)` + fee | minted tokenId + mapping + permit |

**Deploy ↔ project can swap.** Only hard constraints: both exist before `setDeviceContract`; mint before register; mapping before register.

**`applyIoIDs` is optional.** Agent session (`step_5_apply_ioids`) defaults can skip; `step_7` then sets `msg.value = ioIDStore.price()` (pay-as-you-go). Curator/Sentry path is the same family — pre-pay **or** value-on-register, not “must pre-pay.”

**Fee number in the scope doc is off:**

- Live `ioIDStore.price()` = **0.1 IOTX per device** (Pass 2C M5 empirical).
- Scope says “~0.2 IOTX/ioID” and “`applyIoIDs` … 0.2 per ioID” — that was **2 agents × 0.1**, not unit price.
- Register must carry `value = price` **unless** project already has unused applied balance.

**NFT mint `to`:** agent path mints to **bridge**, then register (`user = msg.sender`) consumes and moves device NFT to TBA. Developer-self (gamer = bridge) copies that cleanly. Real third-party gamer later: mint **to gamer** and gamer is `msg.sender` (or explicit 9-param + approval) — do not silently mint-to-bridge then 8-param-register as bridge.

### F2 — **Bigger than “just sendRawTransaction”**: Option-A `device` is wrong in the dry-run assembler

On-chain (Pass 2C / ioIDRegistry):

```text
digest = Permit(user, nonce(device))
require(ecrecover(digest, v, r, s) == device)
```

Agent step-7 (proven):

- `device` = KMS ETH address  
- `user` = `msg.sender` = bridge  
- device signs; `value = price` when pay-as-you-go  
- **ioid tokenId** via `tokenOfOwnerByIndex(bridge, balance-1)` — **not** device NFT tokenId  
- TBA via `ioID.wallet(ioid_token_id)`

Controller dry-run currently:

```404:408:bridge/vapi_bridge/controller_ioid_registration.py
    _device_addr = Web3.to_checksum_address("0x" + device_id_hex.lower().removeprefix("0x")[-40:])
    calldata = assemble_register_calldata(
        device_contract=_ZERO_ADDR,   # VAPIGamerControllerNFT — PREREQ, not deployed
        token_id=0,                   # minted controller tokenId — PREREQ, not minted
```

That truncates `581a836c…` into a fake “ETH address.” Under Option A (gamer signs secp256k1), **`device` must be the gamer EOA** or ecrecover fails. Physical Edge identity is **DID content + birth cert / VMDR**, not the `device` slot.

So the “one real code gap” is slightly larger than send:

1. Fix Option-A register args: `device = gamer`, `user = msg.sender = gamer` (dev-self: bridge).  
2. Wire real `device_contract` + minted `token_id` (not zeros).  
3. Align content hash with agent path (keccak of DID JSON, not keccak of CID string — agents use doc hash).  
4. Real Pinata (CLI still has `_StubPinata`).  
5. `send_raw_transaction` + `value=price` (or prepaid).  
6. Readback: **ioid** tokenId via enumerable on ioID contract, then `wallet(id)` — never assume device NFT id == ioID id (agent bug that already bit them; fixed in step-7).

### F5 — Top footguns (expanded beyond two)

1. **Upgradeable deploy OOG** — Hardhat underestimates ~3–4×; explicit `gasLimit` (init 500k / configureMinter 200k); **`receipt.status === 1n`** every step (agent NFT scars).  
2. **Fee `value`** — forget `msg.value = price` on register when not prepaid → revert; wrong 0.2 unit price in ops notes → overpay or confused budgets.  
3. **`device` ≠ signer** (F2) — silent “invalid signature.”  
4. **`setDeviceContract` 1:1 one-shot** — wrong NFT or reusing agent project → stuck mapping; **controllers need a separate project** (scope is correct).  
5. **TBA / tokenId readback** — `ids(device)` not on deployed registry; use `tokenOfOwnerByIndex`; never equate DeviceNFT tokenId with ioID tokenId.  
6. **Minter allowance** — `configureMinter(bridge, 1)` for single Edge; mint twice without increment fails.  
7. **Pinata stub** — dry-run ok; live register with fake URI is a weak ceremony.
