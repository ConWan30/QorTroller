## F1 — `Number(receipt.status) !== 1` is the correct fix (and dual-safe)

**Root cause confirmed.** ethers v6 returns `receipt.status` as a **number**. In JS:

| compare | result |
|--------|--------|
| `1 !== 1n` | `true` (always “fail”) |
| `Number(1) !== 1` | `false` (pass) |
| `Number(1n) !== 1` | `false` (also pass if a provider ever hands bigint) |

So `Number(x.status) !== 1` is correct **and** more robust than bare `!== 1` (which still false-fails if status is ever bigint).

**Completeness inside the deploy script:** all three write receipts are fixed:

**View smoke uses of bigint are correct** (`total !== 0n`, `allowance !== BigInt(...)`). Do not “fix” those to `Number`.

## F3 — `recover-inca-init.js` adversarial: front-run / TOCTOU / idempotency

### Front-run safety

OZ upgradeable `initialize()` is first-caller-wins; there is **no** atomic “claim if unowned” from a JS script.

| scenario | behavior |
|----------|----------|
| Owner already non-bridge | **ABORT** (L48–50) — correct “front-ran / compromised → redeploy” |
| Owner bridge | SKIP init; only configureMinter if needed |
| Owner zero → race lost to attacker | our `initialize` reverts → `Number(status)!==1` throws → **no** configureMinter, **no** addresses write |
| Owner zero → we win | init → minter config → smoke → write |

**TOCTOU** between `owner()` read and broadcast is real and **unclosable** without on-chain patterns that don’t exist here. Residual is operator-economic (failed gas / must redeploy), not silent corruption. Header documents this; smoke + write-only-on-clean-smoke are correct.

`configureMinter` is `onlyOwner`. Attacker who front-ran init cannot be made minter by this script; re-run hits the non-bridge ABORT.

### Idempotency

- init: only if `owner === ZeroAddress`
- minter: only if `!isMinter || allowance < MINTER_ALLOWANCE`
- re-run after clean recovery: both SKIP paths; smoke still passes; addresses rewrite is harmless

Minor inconsistency (not a bug): deploy smoke requires **exact** allowance; recover smoke allows **≥** `MINTER_ALLOWANCE`. Appropriate for salvage.

### Status checks

Both write receipts use `Number(...status) !== 1`. Smoke keeps bigint views (`total !== 0n`). Good.

### Write path encoding

`JSON.stringify(a, null, 2)` + current note text is pure ASCII. Does not reintroduce cp1252-hostile bytes **with current note content**. If someone later pastes smart quotes into the wiring note template, Node will emit raw UTF-8 again — Python side is now defended by `encoding="utf-8"`.
