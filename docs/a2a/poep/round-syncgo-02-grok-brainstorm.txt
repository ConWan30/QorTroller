### B1 — CLI preflight (primary)

**File:** `scripts/poep_session_identity_attach.py` (orchestration shell only; prefer **not** editing sealed `challenge_live` / `classify_activity`).

Add something equivalent to:

```text
--wait-active-s FLOAT   default 45 (0 = no wait, current behavior)
--amplitude INT         default 60, clamp 1..80 (LOW_AMPLITUDE_FORCE_MAX)
--poll-s FLOAT          default 1.0 between preflight samples
```

**Preflight loop (live only, before `run_session_identity_attach` or as wrapper that only starts challenges when ready):**

1. GET capture-health (same URL as fetcher).
2. Ready when ALL of:
   - `capture_state` in {NOMINAL} (match pcc_allows_challenge / existing PCC set)
   - `host_state` in {EXCLUSIVE_USB, UNKNOWN} if that is what `pcc_allows_challenge` already allows — **read the sealed helper; do not invent a looser set**
   - `live_activity_window_n >= 3`
   - `live_trigger_active_fraction > 0`  → ACTIVE_GAMEPLAY under sealed grammar
3. Else sleep `poll-s`, print one stderr line:
   `waiting active play: frac=… window_n=… capture=… host=… (…s left)`
4. On timeout: print `PREFLIGHT TIMEOUT: no ACTIVE_GAMEPLAY within Ns — attach will still run and honestly refuse GOs` OR exit 3 with clear message — **pick one and document**; prefer **exit 3** so operator does not get a silent IDENTITY_ONLY with n_go=0 thinking fires ran.
5. On ready: proceed into existing `run_session_identity_attach`.

**Amplitude:** pass through to `challenge_live(..., amplitude=args.amplitude)` if the runner currently hardcodes default — thread amp from CLI → `run_session_identity_attach` → each `challenge_live` call. **Do not** change sealed default constant unless necessary; CLI override is enough.

**Preferred architecture:** keep purity of `poep_session_identity_run.py` (no candidate forge). Either:
- preflight only in the **script** then call runner, or
- add optional `wait_active_s` / `amplitude` kwargs to the runner that only loop `poll_bridge_activity` until ACTIVE or timeout **before** the challenge for-loop — still never sets candidate bits.
