# Welcome to QorTroller

QorTroller is the **parent** V.A.P.I. project — the truth plane for gamer-owned controller data.

Anyone can:

1. Clone https://github.com/ConWan30/QorTroller
2. Run `python scripts/vapi_invariant_gate.py`
3. Run `python scripts/verify_wmp_ladder.py`
4. Read Pages at https://conwan30.github.io/QorTroller/

You do **not** need a GitHub PAT, wallet key, or Buzz secret to do any of that.

The observation-plane sibling is [Qoresence](https://github.com/ConWan30/Qoresence). Use that repo for HDMI / Deck / glasses. Use this repo for receipts, consent, and protocol claims.

If you are filing a security issue, use a [private advisory](https://github.com/ConWan30/QorTroller/security/advisories/new), not this thread.
