# QorTroller Agentic Charter v0 (deprecated)

**Status:** superseded  
**Superseded by:** [`qortroller-agentic-charter-v1.md`](qortroller-agentic-charter-v1.md)

## What v0 optimized for

- Agents as first-class **Buzz members**
- **Create** channel / agent / project as the main power
- Open-ended mint; creation receipt treated like progress
- Unlimited children; Buzz-native for its own sake

## Why it was redesigned

QorTroller’s purpose is **cryptographically real human play**, **gamer sovereignty**, and **honest social pointers** — not agent theater. v1 binds agents to purpose clauses, structured handoffs, and truth/ops/sense-making planes so agents never become the authority of record.

## Do not extend v0

Keep this file for historical reference only. All new agent, channel, and hire work follows **charter v1**.
